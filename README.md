# 4분 운동 타이머

브라우저에서 바로 실행되는 한국어 인터벌 타이머입니다. `index.html`을 열거나 GitHub Pages에서 사용할 수 있습니다. 설치와 외부 라이브러리가 필요하지 않으며 오프라인에서도 작동합니다.

## 루틴

| 운동 | 운동 시간 | 휴식 |
|---|---:|---:|
| 버피 | 45초 | 15초 |
| 점프스쿼트 | 30초 | 30초 |
| 플랭크 잭 | 30초 | 30초 |
| 턱업 | 30초 | 30초 |

- 시작 전 5초 준비시간, 총 운동·휴식 시간 4분
- 스페이스바 또는 버튼으로 재생·일시정지
- 각 구간의 마지막 10초 동안 매초 높은음 → 낮은음으로 이어지는 이중 비프음 (전체 음높이 반음 낮춤)
- 초 알림은 단음 beep · 운동 시작 도미솔 · 운동 종료 솔미도 · 루틴 완료 솔파미레도
- 알림음 켜기/끄기 및 테스트 버튼
- 배경음악 없음
- Google Fonts Orbitron 숫자 글꼴 내장 · 운동 종료 10초 전부터만 빨간색 표시 (휴식 제외)

## GitHub Pages

저장소의 **Settings → Pages → Deploy from a branch**에서 **main / (root)**를 선택해 배포합니다.

## 글꼴 라이선스

Orbitron은 SIL Open Font License 1.1을 따릅니다. 글꼴의 저작권 및 라이선스 전문은 `index.html`에 포함되어 있습니다.
